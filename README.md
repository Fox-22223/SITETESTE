# NOVA — Explore além do horizonte

Uma experiência visual e interativa sobre exploração espacial, desenvolvida com **HTML, CSS e JavaScript puro**, sem ferramentas de compilação ou dependências de execução.

## Experimente

Abra o arquivo **index.html** em um navegador moderno. Para publicar na web, siga as instruções de GitHub Pages abaixo.

### O que funciona

- **Início:** experiência de boas-vindas, planeta ilustrado com CSS, estatísticas e destinos em destaque.
- **Explorar:** catálogo de seis planetas, busca por nome, filtros por tipo, fichas com informações e curiosidades.
- **Missões:** três missões conceituais e uma simulação de decolagem com contagem regressiva.
- **Coleção:** salve ou remova planetas favoritos; os dados ficam no armazenamento local do navegador.
- **Tema claro/escuro:** preferência persistida no navegador.
- **Acessibilidade:** navegação por teclado, foco visível, fechamento de janelas com Escape, estados dos botões acessíveis e suporte a movimento reduzido.
- **Responsivo:** layouts adaptados para desktop, tablet e celular.

## Publicar gratuitamente no GitHub Pages

1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch **main** e a pasta **/(root)** e clique em **Save**.
4. Quando o GitHub concluir a publicação, abra o endereço exibido pela própria área de Pages (geralmente https://fox-22223.github.io/SITETESTE/).

O projeto funciona também em outras hospedagens de sites estáticos.

## Arquivos

- index.html — estrutura e conteúdo das páginas.
- styles.css — identidade visual, planetas ilustrados em CSS, animações e layout responsivo.
- app.js — navegação, catálogo, filtros, favoritos, tema, diálogos e simulação.
- favicon.svg — ícone vetorial da aplicação.

## Observações

As missões **Aurora I**, **Titan Deep** e **Blue Horizon** são fictícias, assim como suas simulações. Os planetas e os dados astronômicos são reais, com números arredondados para fins de divulgação e temperaturas representativas aproximadas.

O site não depende de API, não solicita contas ou senhas e não envia favoritos para um servidor. Apenas as fontes opcionais usam Google Fonts.
